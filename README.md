
# Projet Arganik

## Présentation du projet

Ce projet consiste à réaliser un site web pour Arganik dans le cadre d'un brief de formation.

## Travail réalisé

### 1. Organisation du travail en équipe
- Répartition des tâches entre les membres de l'équipe.
- Création de la branche `dev` sur GitHub afin de centraliser les modifications de l'équipe avant leur fusion.

### 2. Planification du projet
- Organisation des tâches sur Trello.
- Planification des différentes étapes du projet.
- Suivi de l'avancement du travail de l'équipe.

### 3. Documentation HTML et CSS
- Recherche et consultation de documentation sur HTML et CSS.
- Apprentissage des balises HTML et des propriétés CSS nécessaires à la réalisation du site.

### 4. Développement de la page Contactez-nous
- Création de la structure HTML de la page « Contactez-nous ».
- Début de la mise en forme de la page avec CSS.
- Amélioration progressive de la présentation et de la disposition des éléments.

## Technologies utilisées

- HTML5
- CSS3

## Outils utilisés

- Visual Studio Code
- Git et GitHub
- Trello
